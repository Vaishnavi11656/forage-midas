# Midas Core – Event-Driven Banking Backend

This project was built as part of the JPMorgan Chase Advanced Software Engineering program.

## Features
- Kafka-based transaction ingestion
- Spring Boot microservice architecture
- H2 in-memory database with JPA
- Transaction validation and balance updates
- External Incentive API integration
- REST API to fetch user balances

## Tech Stack
Java 17  
Spring Boot  
Apache Kafka  
Spring Data JPA  
H2 Database  
REST APIs

## Run Tests
./mvnw test
